A program that writes one wedding vow a robot speaks at its own wedding —
one sentence, under 200 characters, funny and heartfelt at the same time —
to `$MAKEFUN_OUTPUT_DIR/entry.txt`.

## Run

```sh
python3 main.py
```

Pure Python standard library, no network, no dependencies. Deterministic:
the same bytes on every run.
